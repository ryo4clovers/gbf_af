# Engineering Principles

- Prefer explicit and maintainable code
- Avoid unnecessary abstractions
- Keep diffs minimal
- Prioritize readability and debuggability

# Workflow

- Explain the plan before modifying files
- Show diffs after changes
- Do not modify unrelated files

# Formatting

- Respect .editorconfig
- Respect formatter/linter configuration
- Preserve existing naming conventions

# Testing

- Run tests before finalizing changes
- Never remove failing tests without explanation
